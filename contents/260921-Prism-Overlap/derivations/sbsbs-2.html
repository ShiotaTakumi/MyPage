Proof that the family $\mathsf{SBSBS}$-2 does not overlap for $h_1(n) \le h \le h_2(n)$族 $\mathsf{SBSBS}$-2 が $h_1(n) \le h \le h_2(n)$ で重ならないことの証明

$\mathsf{SBSBS}$-2. $\ell_0 = 2$, $p_1 = 2$, $d_1 = +1$, $\ell_1 = 1$, $p_2 = 3$, $d_2 = +1$, $\ell_2 = n - 3$, $13 \le n \le 25$. The two end faces do not overlap for $h_1(n) \le h \le h_2(n)$.

$\mathsf{SBSBS}$-2. $\ell_0 = 2$、$p_1 = 2$、$d_1 = +1$、$\ell_1 = 1$、$p_2 = 3$、$d_2 = +1$、$\ell_2 = n - 3$、$13 \le n \le 25$。$h_1(n) \le h \le h_2(n)$ では、両端の面は重ならない。

1. Coordinates1. 座標

Throughout, $\alpha = 2\pi/n$; the vertices of $\mathsf{B}_1$ and $\mathsf{B}_2$ are $b_j$ and $t_j$ (the side face $s_j$ has the vertices $b_j$, $b_{j+1}$, $t_{j+1}$, $t_j$); the corners of the end face $\mathsf{S}_2$, which carries the line of Section 2, are $r_1, \dots, r_4$; and those of the other end face $\mathsf{S}_1$ are $q_1, \dots, q_4$.

以下、$\alpha = 2\pi/n$ とし、$\mathsf{B}_1$、$\mathsf{B}_2$ の頂点を $b_j$、$t_j$（側面 $s_j$ の頂点は $b_j$、$b_{j+1}$、$t_{j+1}$、$t_j$）、2 節の直線を持つ端の面 $\mathsf{S}_2$ の角を $r_1, \dots, r_4$、もう一方の端の面 $\mathsf{S}_1$ の角を $q_1, \dots, q_4$ とする。

Coordinates座標Formula式
$b_j$$\left(\sum_{i=0}^{j-1} \cos i\alpha,\ \sum_{i=0}^{j-1} \sin i\alpha\right)$
$t_j$$\left(1 + \sum_{i=0}^{j-2} \cos i\alpha,\ -h - \sum_{i=0}^{j-2} \sin i\alpha\right) \quad (1 \le j \le n)$
$r_1$$t_{3}$
$r_3$$t_{3} + h(\sin 2\alpha, \cos 2\alpha)$
$q_1$$b_{2}$
$q_2$$b_{2} + (\cos 2\alpha, \sin 2\alpha)$
$q_3$$b_{2} + h(\sin 2\alpha, -\cos 2\alpha)$
$q_4$$b_{2} + (\cos 2\alpha, \sin 2\alpha) + h(\sin 2\alpha, -\cos 2\alpha)$

2. Signed distances2. 符号付き距離

        
The line through $r_1$ and $r_3$ has the unit normal $(-\cos 2\alpha, \sin 2\alpha)$ pointing away from $\mathsf{S}_2$. Let $f_v(h) = (v - r_1) \cdot (-\cos 2\alpha, \sin 2\alpha)$ be the signed distance of a point $v$ from the line; $\mathsf{S}_2$ lies in $f \le 0$, which is the half-plane $H$ of the lemma of Section 8 of the home page. For the corners of $\mathsf{S}_1$, the product-to-sum formulas give

        
$r_1$ と $r_3$ を通る直線の、$\mathsf{S}_2$ から離れる向きの単位法線は $(-\cos 2\alpha, \sin 2\alpha)$ である。点 $v$ のこの直線からの符号付き距離を $f_v(h) = (v - r_1) \cdot (-\cos 2\alpha, \sin 2\alpha)$ とおく。$\mathsf{S}_2$ は $f \le 0$ の側、すなわちホームの 8 節の補題の $H$ に入る。$\mathsf{S}_1$ の角については、積和の公式から次を得る。

        

          \[
          \begin{aligned}
      f_{q_1}(h) &= h\sin 2\alpha + \cos\alpha + \cos 2\alpha - \cos 3\alpha \\
      f_{q_2}(h) &= h\sin 2\alpha + \cos\alpha + \cos 2\alpha - \cos 3\alpha - \cos 4\alpha \\
      f_{q_3}(h) &= h(\sin 2\alpha - \sin 4\alpha) + \cos\alpha + \cos 2\alpha - \cos 3\alpha \\
      f_{q_4}(h) &= h(\sin 2\alpha - \sin 4\alpha) + \cos\alpha + \cos 2\alpha - \cos 3\alpha - \cos 4\alpha
          \end{aligned}
          \]

from sympy import symbols, sin, cos, pi, lambdify, minimal_polynomial
from mpmath import iv
alpha, h, X = symbols("alpha h X")
# f_{q_1}, f_{q_2}, f_{q_3}, f_{q_4} of Section 2, and h_1(n), h_2(n)
f = [h*sin(2*alpha) + cos(alpha) + cos(2*alpha) - cos(3*alpha),
     h*sin(2*alpha) + cos(alpha) + cos(2*alpha) - cos(3*alpha) - cos(4*alpha),
     h*(sin(2*alpha) - sin(4*alpha)) + cos(alpha) + cos(2*alpha) - cos(3*alpha),
     h*(sin(2*alpha) - sin(4*alpha)) + cos(alpha) + cos(2*alpha) - cos(3*alpha) - cos(4*alpha)]
def h1(n):
    if n <= 16:
        return (sin(3*alpha) - sin(2*alpha))/(cos(alpha) - cos(3*alpha))
    if n <= 19:
        return (cos(4*alpha) + 2 - cos(alpha) - cos(2*alpha))/sin(3*alpha)
    return (2*sin(5*alpha) - sin(4*alpha) - sin(3*alpha) + sin(alpha))/(cos(2*alpha) - cos(5*alpha))
h2 = lambda n: (cos(alpha) - cos(3*alpha))/(sin(3*alpha) - sin(2*alpha))
iv.dps = 50


def value(x, n):
    """x at alpha = 2 pi/n, as an interval that contains it: sin, cos, pi and the fractions
    (mpf(p)/mpf(q)) are those of the interval arithmetic of mpmath."""
    names = {"sin": iv.sin, "cos": iv.cos, "pi": iv.pi, "mpf": iv.mpf}
    return iv.mpf(lambdify(alpha, x, [names, "mpmath"])(2*iv.pi/n))


def positive(x, n):
    """Whether x > 0 at alpha = 2 pi/n. Only if its interval contains 0, x is tested for 0
    exactly (by its minimal polynomial), and if it is not 0, evaluated with more digits."""
    v = value(x, n)
    if 0 in v:
        print(f"n = {n}: the interval contains 0; tested exactly")
        if minimal_polynomial(x.subs(alpha, 2*pi/n), X) == X:
            return False
        while 0 in v:
            iv.dps *= 2
            v = value(x, n)
        iv.dps = 50
    return v.a > 0


ok = True
for k, H in ((1, h1), (2, h2)):
    print(f"At h = h_{k}(n):")

        fs = [x.subs(h, H(n)) for x in f]
        print(n, *(f"{float(value(x, n).mid):.6f}" for x in [H(n)] + fs))
        ok = ok and all(positive(x, n) for x in fs)
print("Every value is positive:", ok)
