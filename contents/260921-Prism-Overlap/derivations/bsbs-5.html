Proof that the family $\mathsf{BSBS}$-5 does not overlap for $h_1(n) \le h \le h_2(n)$族 $\mathsf{BSBS}$-5 が $h_1(n) \le h \le h_2(n)$ で重ならないことの証明

$\mathsf{BSBS}$-5. $\ell_0 = 2$, $p_2 = n - 3$, $d_2 = +1$, $\ell_2 = 3$, $21 \le n \le 25$. The two end faces do not overlap for $h_1(n) \le h \le h_2(n)$.

$\mathsf{BSBS}$-5. $\ell_0 = 2$、$p_2 = n - 3$、$d_2 = +1$、$\ell_2 = 3$、$21 \le n \le 25$。$h_1(n) \le h \le h_2(n)$ では、両端の面は重ならない。

1. Coordinates1. 座標

Throughout, $\alpha = 2\pi/n$; the vertices of $\mathsf{B}_1$ and $\mathsf{B}_2$ are $b_j$ and $t_j$ (the side face $s_j$ has the vertices $b_j$, $b_{j+1}$, $t_{j+1}$, $t_j$); and the corners of the end face $\mathsf{S}_2$, which carries the line of Section 2, are $r_1, \dots, r_4$ (the other end face is $\mathsf{B}_1$, whose vertices $b_j$ are checked).

以下、$\alpha = 2\pi/n$ とし、$\mathsf{B}_1$、$\mathsf{B}_2$ の頂点を $b_j$、$t_j$（側面 $s_j$ の頂点は $b_j$、$b_{j+1}$、$t_{j+1}$、$t_j$）、2 節の直線を持つ端の面 $\mathsf{S}_2$ の角を $r_1, \dots, r_4$ とする（もう一方の端の面は $\mathsf{B}_1$ で、その頂点 $b_j$ を調べる）。

Coordinates座標Formula式
$b_j$$\left(\sum_{i=0}^{j-1} \cos i\alpha,\ \sum_{i=0}^{j-1} \sin i\alpha\right)$
$t_j$$\left(1 + \sum_{i=0}^{j-2} \cos i\alpha,\ -h - \sum_{i=0}^{j-2} \sin i\alpha\right) \quad (1 \le j \le n)$
$r_2$$t_{n - 3} + 3(\cos 4\alpha, \sin 4\alpha)$
$r_4$$t_{n - 3} + 3(\cos 4\alpha, \sin 4\alpha) + h(-\sin 4\alpha, \cos 4\alpha)$

2. Signed distances2. 符号付き距離

        
The line through $r_2$ and $r_4$ has the unit normal $(\cos 4\alpha, \sin 4\alpha)$ pointing away from $\mathsf{S}_2$. Let $f_v(h) = (v - r_2) \cdot (\cos 4\alpha, \sin 4\alpha)$ be the signed distance of a point $v$ from the line; $\mathsf{S}_2$ lies in $f \le 0$, which is the half-plane $H$ of the lemma of Section 8 of the home page. The vertices of $\mathsf{B}_1$ lie on a circle, and the direction of the line does not depend on $h$. Hence, for each $n$, $f_{b_j}(h) = C + R\cos(j\alpha - \varphi)$ with constants $R$ and $\varphi$, and only $C$ depending on $h$, is smallest at the vertex nearest the line. That vertex is one of the four below (two of them tie when the line is parallel to an edge of $\mathsf{B}_1$). For these, the product-to-sum formulas give

        
$r_2$ と $r_4$ を通る直線の、$\mathsf{S}_2$ から離れる向きの単位法線は $(\cos 4\alpha, \sin 4\alpha)$ である。点 $v$ のこの直線からの符号付き距離を $f_v(h) = (v - r_2) \cdot (\cos 4\alpha, \sin 4\alpha)$ とおく。$\mathsf{S}_2$ は $f \le 0$ の側、すなわちホームの 8 節の補題の $H$ に入る。$\mathsf{B}_1$ の頂点は円周上にあり、直線の向きは $h$ によらない。よって各 $n$ で、$f_{b_j}(h) = C + R\cos(j\alpha - \varphi)$（$R$、$\varphi$ は定数で、$h$ によるのは $C$ だけ）は直線に最も近い頂点で最小となる。その頂点は下の 4 つのどれかである（直線が $\mathsf{B}_1$ の辺と平行なときは 2 つが同じ値になる）。これらについて、積和の公式から次を得る。

        

          \[
          \begin{aligned}
      f_{b_{n - 3}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - \cos 6\alpha - \cos 7\alpha - 2 \\
      f_{b_{n - 2}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - \cos 6\alpha - 2 \\
      f_{b_{n - 1}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - 2 \\
      f_{b_{0}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - 2
          \end{aligned}
          \]

def value(x, n):
    """x at alpha = 2 pi/n, as an interval that contains it: sin, cos, pi and the fractions
    (mpf(p)/mpf(q)) are those of the interval arithmetic of mpmath."""
    names = {"sin": iv.sin, "cos": iv.cos, "pi": iv.pi, "mpf": iv.mpf}
    return iv.mpf(lambdify(alpha, x, [names, "mpmath"])(2*iv.pi/n))


def positive(x, n):
    """Whether x > 0 at alpha = 2 pi/n. Only if its interval contains 0, x is tested for 0
    exactly (by its minimal polynomial), and if it is not 0, evaluated with more digits."""
    v = value(x, n)
    if 0 in v:
        print(f"n = {n}: the interval contains 0; tested exactly")
        if minimal_polynomial(x.subs(alpha, 2*pi/n), X) == X:
            return False
        while 0 in v:
            iv.dps *= 2
            v = value(x, n)
        iv.dps = 50
    return v.a > 0
