2. Signed distances2. 符号付き距離

The line through $p_2 p_4$ has the unit normal $(\cos 4\alpha, \sin 4\alpha)$ pointing away from $\mathsf{S}_2$. Let $f_v(h) = (v - p_2) \cdot (\cos 4\alpha, \sin 4\alpha)$ be the signed distance of a point $v$ from the line; $\mathsf{S}_2$ lies in $f \le 0$, which is the half-plane $H$ of the lemma of Section 8 of the home page. The vertices of $\mathsf{B}_1$ lie on a circle and the direction of the line does not depend on $h$, so for each $n$, $f_{b_j}(h) = C + R\cos(j\alpha - \varphi)$, where only $C$ depends on $h$, is smallest at the vertex nearest the line, which is one of the four below (two of them tie when the line is parallel to an edge of $\mathsf{B}_1$). For these, the product-to-sum formulas give

$p_2 p_4$ を通る直線の、$\mathsf{S}_2$ から離れる向きの単位法線は $(\cos 4\alpha, \sin 4\alpha)$ である。点 $v$ のこの直線からの符号付き距離を $f_v(h) = (v - p_2) \cdot (\cos 4\alpha, \sin 4\alpha)$ とおく。$\mathsf{S}_2$ は $f \le 0$ の側、すなわちホームの 8 節の補題の $H$ に入る。$\mathsf{B}_1$ の頂点は円周上にあり、直線の向きは $h$ によらないので、各 $n$ で $f_{b_j}(h) = C + R\cos(j\alpha - \varphi)$（$h$ によるのは $C$ だけ）は直線に最も近い頂点で最小となり、その頂点は下の 4 つのどれかである（直線が $\mathsf{B}_1$ の辺と平行なときは 2 つが同じ値になる）。これらについて、積和の公式から次を得る。

\[ \begin{aligned} f_{b_{n - 3}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - \cos 6\alpha - \cos 7\alpha - 2 \\ f_{b_{n - 2}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - \cos 6\alpha - 2 \\ f_{b_{n - 1}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - \cos 5\alpha - 2 \\ f_{b_{0}}(h) &= h\sin 4\alpha + \cos\alpha + \cos 2\alpha + \cos 3\alpha - \cos 4\alpha - 2. \end{aligned} \]

#!/usr/bin/env python3
"""BSBS-5: the two end faces do not overlap for h_1(n) <= h <= h_2(n), where 21 <= n <= 25.

The family has l0 = 2, p2 = n - 3, d2 = 1, l2 = 3 (pattern BSBS, with no band S1). Its two end faces
are B1 and S2, and the line is the one through the end p_2 p_4 of S2, at its last side face s_{n-1}.
The vertices of the prism are b_j on B1 and t_j on B2, where the side face s_j has the vertices b_j,
b_{j+1}, t_{j+1}, t_j (the labels are taken modulo n), and alpha = 2 pi / n.

The path partial unfolding is laid down as on the page of the family:
  - B1 has the vertices b_j = sum_{i<j} (cos i alpha, sin i alpha), counterclockwise from
    b_0 = (0, 0) and b_1 = (1, 0);
  - the band S0 = {s_0, ..., s_{l0-1}} lies below the edge b_0 b_1, along the x-axis;
  - B2 is joined below the last side face of S0, as a mirror image of B1;
  - the band S2 lies along the edge t_{p2} t_{p2+1} of B2, outside B2.
The corners of S2 are p_1, on B2 at the side face s_{p2}, p_2, on B2 at the other end, and
p_3 = p_1 + h u and p_4 = p_2 + h u, where u is the unit normal to the edge t_{p2} t_{p2+1} pointing
away from B2.
For each vertex b_j of B1, f_{b_j}(h) = (b_j - p_2) . (cos 4 alpha, sin 4 alpha) is its signed
distance from the line, positive on the side away from S2. It has the form A + B h, where A and B
depend on alpha only. The program prints A and B for the vertices b_{n-3}, b_{n-2}, b_{n-1}, b_0 of
B1, and then their f(h_1(n)) and f(h_2(n)) for each n; for each n, it also checks that
f_{b_j}(h_1(n)) > 0 and f_{b_j}(h_2(n)) > 0 for every j = 0, ..., n - 1, and that the smallest
f_{b_j} is at one of these vertices (f_{b_j} - f_{b_k} does not depend on h). The signs are decided
by interval arithmetic (mpmath, 50 digits), which gives an interval that contains the exact value;
only if the interval contains 0, the value is tested for 0 exactly (by its minimal polynomial), and,
if it is not 0, computed again with twice as many digits until the interval does not contain 0.

SymPy is needed (pip install sympy; mpmath comes with it). The program also runs in the browser,
with Pyodide, on the page of the family.
"""

import sympy as sp
from mpmath import iv
from sympy.simplify.fu import TR8

iv.dps = 50

a, h = sp.symbols("alpha h", positive=True)
vec = lambda x, y: sp.Matrix([x, y])
cos = lambda k: sp.cos(k * a)
sin = lambda k: sp.sin(k * a)

# The family and the line
L0, P2, D2, L2 = 2, -3, 1, 3
# p2 = n - 3 is written -3: the labels are taken modulo n
NS = range(21, 26)
SHOWN = [-3, -2, -1, 0]         # the vertices b_j of B1 in the tables: b_{n-3}, b_{n-2}, b_{n-1}, b_0


# ------------------------------------------------------------------ the unfolding

def b(j):
    """The vertex b_j of B1."""
    if j >= 0:
        return vec(sum(cos(i) for i in range(j)), sum(sin(i) for i in range(j)))
    return -vec(sum(cos(i) for i in range(j, 0)), sum(sin(i) for i in range(j, 0)))


def turn(v, k):
    """The vector v turned by k alpha."""
    return vec(cos(k) * v[0] - sin(k) * v[1], sin(k) * v[0] + cos(k) * v[1])


def t(j):
    """The vertex t_j of B2. The last side face s_{l0-1} of S0 has its side on B2 from (l0 - 1, -h)
    to (l0, -h); B2 is B1 turned so that its edge b_{l0-1} b_{l0} is horizontal, reflected in the
    x-axis, and moved so that this edge lies on that side."""
    q = turn(b(j) - b(L0 - 1), -(L0 - 1))
    return vec(L0 - 1 + q[0], -h - q[1])


def band(corner, P, D, L, right):
    """The band of the L side faces s_P, s_{P+D}, ... that lies along the edge from corner(P) to
    corner(P + 1) of a base, outside the base: on the right of the edge if right, else on its left.
    Returns its corners [c_1, c_2, c_3, c_4], the unit vector along it from c_1 to c_2, and the unit
    normal to the edge pointing away from the base."""
    edge = corner(P + 1) - corner(P)                        # a unit vector
    out = vec(edge[1], -edge[0]) if right else vec(-edge[1], edge[0])
    start = corner(P) if D == 1 else corner(P + 1)          # c_1, at the side face s_P
    along = D * edge
    return [start, start + L * along, start + h * out, start + L * along + h * out], along, out


p, along2, out2 = band(t, P2, D2, L2, right=False)      # S2; B2 is clockwise


# ------------------------------------------------------------------ the signed distances

normal = along2                          # the unit normal to the end p_2 p_4 of S2 pointing away from S2
f = [sp.expand((b(j) - p[1]).dot(normal)) for j in SHOWN]
A = [sp.expand(TR8(x.coeff(h, 0))) for x in f]      # product-to-sum
B = [sp.expand(TR8(x.coeff(h, 1))) for x in f]


# ------------------------------------------------------------------ the two ends of the interval

def h1(n):
    """h_1(n) (Section 2 of the home page), in alpha."""
    if n <= 12:
        return (sin(3) - sin(2)) / cos(1)
    if n <= 16:
        return (sin(3) - sin(2)) / (cos(1) - cos(3))
    if n <= 19:
        return (cos(4) + 2 - cos(1) - cos(2)) / sin(3)
    return (2 * sin(5) - sin(4) - sin(3) + sin(1)) / (cos(2) - cos(5))


def h2(n):
    """h_2(n) (Section 2 of the home page), in alpha."""
    return cos(1) / (sin(3) - sin(2)) if n == 11 else (cos(1) - cos(3)) / (sin(3) - sin(2))


def at(expr, n):
    """expr at alpha = 2 pi / n, as an interval that contains its exact value. Every number in expr
    becomes an interval: sin, cos, pi and the fractions (written mpf(p)/mpf(q)) are those of iv, and so
    is an integer, which expr may reduce to."""
    names = {"sin": iv.sin, "cos": iv.cos, "pi": iv.pi, "mpf": iv.mpf}
    return iv.mpf(sp.lambdify(a, expr, modules=[names, "mpmath"])(2 * iv.pi / n))


def sign(expr, n):
    """The sign of expr at alpha = 2 pi / n, decided as described at the top."""
    digits = iv.dps
    try:
        while True:
            x = at(expr, n)
            if x.a > 0:
                return 1
            if x.b < 0:
                return -1
            if iv.dps == digits:                        # only once: is the value exactly 0?
                X = sp.Symbol("X")
                if sp.minimal_polynomial(expr.subs(a, 2 * sp.pi / n), X) == X:
                    return 0
            iv.dps *= 2
    finally:
        iv.dps = digits


def values(n):
    """[(h, [f_{b_j}(h) for the vertices b_j in SHOWN])] at h = h_1(n) and h = h_2(n), as intervals."""
    out = []
    for H in (h1(n), h2(n)):
        out.append((at(H, n), [at(A[k] + B[k] * H, n) for k in range(len(SHOWN))]))
    return out


def every_vertex(n):
    """Whether f_{b_j}(h_1(n)) > 0 and f_{b_j}(h_2(n)) > 0 for every vertex b_j of B1, and the
    smallest f_{b_j} is at a vertex in SHOWN: every other f_{b_j} is larger than one of those (the
    difference does not depend on h)."""
    shown = [j % n for j in SHOWN]
    fb = [sp.expand((b(j) - p[1]).dot(normal)) for j in range(n)]
    outside = all(sign(x.subs(h, H), n) == 1 for H in (h1(n), h2(n)) for x in fb)
    nearest = all(any(sign(fb[j] - fb[k], n) == 1 for k in shown) for j in range(n) if j not in shown)
    return outside and nearest


def main():
    names = [f"b_{j}" if j >= 0 else f"b_{{n{j}}}" for j in SHOWN]
    print(f"f_b(h) = A + B h for the vertices {', '.join(names)} of B1:")
    for name, x, y in zip(names, A, B):
        print(f"  {name}:  A = {x}")
        print(f"  {' ' * len(name)}   B = {y}")
    positive = True
    for side, name in enumerate(("h_1(n)", "h_2(n)")):
        print(f"\nAt h = {name}:")
        print("   n         h" + "".join(f"{'f(' + x + ')':>12}" for x in names))
        for n in NS:
            H, fs = values(n)[side]
            end = (h1, h2)[side](n)
            positive &= all(sign(A[k] + B[k] * end, n) == 1 for k in range(len(SHOWN)))
            print(f"  {n:2d}  {float(H.mid):8.6f}" + "".join(f"{float(x.mid):12.6f}" for x in fs))
    every = all(every_vertex(n) for n in NS)
    print("\nFor every n: f_{b_j}(h_1(n)) > 0 and f_{b_j}(h_2(n)) > 0 for j = 0, ..., n - 1, and the "
          "smallest f_{b_j} is in the tables." if every else "\nSome vertex of B1 is not shown to be so.")
    print("\nEvery value is positive." if positive and every else "\nSome value is not shown to be positive.")


if __name__ == "__main__":
    main()

#!/usr/bin/env wolframscript
(* ::Package:: *)

(* BSBS-5: the two end faces do not overlap for h_1(n) <= h <= h_2(n), where 21 <= n <= 25.

   Mathematica version of bsbs-5.py, written separately from it. The family has l0 = 2, p2 = n - 3,
   d2 = 1, l2 = 3, and the line is the one through the end p_2 p_4 of S2, at its last side face
   s_{n-1}. The script lays the path partial unfolding down in the coordinates of the page (B2 is
   walked along its edges here, instead of being obtained as a mirror image of B1, and each band is
   walked along its base one side face at a time), checks that the signed distances f_{b_j}(h) of
   the vertices b_{n-3}, b_{n-2}, b_{n-1}, b_0 of B1 from the line equal the formulas on the page,
   that they are positive at h_1(n) and h_2(n), and, for every n, that f_{b_j}(h_1(n)) > 0 and
   f_{b_j}(h_2(n)) > 0 for every j = 0, ..., n - 1 and that the smallest f_{b_j} is at one of these
   vertices. Identities in alpha are verified as (left side) - (right side) = 0. The sign of a
   number for a particular n (alpha = 2 Pi/n) is decided by interval arithmetic, and, only if the
   interval contains 0, exactly, as the sign of the algebraic number that RootReduce gives.

   Run:  wolframscript -file bsbs-5.wls *)

$Assumptions = a > 0 && h > 0;

passed = 0; failed = 0;
(* zero as an identity in alpha: after TrigReduce (products to sums), else by FullSimplify *)
zeroQ[e_List] := AllTrue[Flatten[e], zeroQ];
zeroQ[e_] := TrigReduce[Expand[e]] === 0 || FullSimplify[e] === 0;
check[label_String, e_] := If[zeroQ[e],
  passed++; Print[label, "  OK"],
  failed++; Print[label, "  NG: ", InputForm[FullSimplify[e]]]];
checkTrue[label_String, b_] := If[TrueQ[b],
  passed++; Print[label, "  OK"],
  failed++; Print[label, "  NG: ", b]];

(* the sign of x, an expression in a, at a = 2 Pi/n. First by interval arithmetic: a is replaced by an
   interval of 80 digits that contains 2 Pi/n, and Mathematica computes an interval that contains the
   value, rounding outward. Only if this interval contains 0 is the sign decided exactly: RootReduce
   gives the value as an algebraic number (a Root object with an isolating interval), whose sign
   Mathematica decides exactly. exact counts these. *)
exact = 0;
around[n_] := With[{c = N[2 Pi/n, 80]}, Interval[{c - 10^-70, c + 10^-70}]];
sgn[x_, n_] := With[{v = x /. a -> around[n]},
  Which[Min[v] > 0, 1, Max[v] < 0, -1, True, exact++; Sign[RootReduce[x /. a -> 2 Pi/n]]]];
positiveQ[x_, n_] := sgn[x, n] === 1;

(* ------------------------------------------------------------ the family *)

{l0, p2, d2, l2} = {2, -3, 1, 3};      (* p2 = n - 3 is written -3: the labels are taken modulo n *)
ns = Range[21, 25];
shown = {-3, -2, -1, 0};                        (* the vertices of B1 in the tables: b_{n-3}, b_{n-2}, b_{n-1}, b_0 *)
names = {"b_{n-3}", "b_{n-2}", "b_{n-1}", "b_0"};

(* ------------------------------------------------------------ the unfolding *)

(* B1: b_0 = (0, 0), b_1 = (1, 0), counterclockwise; the edge b_j b_{j+1} has the direction j a *)
b[j_] := If[j >= 0, Sum[{Cos[i a], Sin[i a]}, {i, 0, j - 1}],
  -Sum[{Cos[i a], Sin[i a]}, {i, j, -1}]];           (* b_j, j < 0, walked back from b_0 *)

(* S0 lies below b_0 b_1 along the x-axis, and B2 below its last side face, from t_{l0-1} = (l0 - 1, -h)
   to t_{l0} = (l0, -h). B2 is walked clockwise from there: its edge t_j t_{j+1} has the direction
   -(j - (l0 - 1)) a *)
dir2[j_] := {Cos[(j - (l0 - 1)) a], -Sin[(j - (l0 - 1)) a]};
t[j_] := If[j >= l0 - 1, {l0 - 1, -h} + Sum[dir2[i], {i, l0 - 1, j - 1}],
  {l0 - 1, -h} - Sum[dir2[i], {i, j, l0 - 2}]];      (* t_j, j < l0 - 1, walked back *)

(* a band of l side faces s_p, s_(p+d), ... along an edge of a base with the direction dir, outside the
   base: from its corner c_1 on the base at the side face s_p, it is walked along the base one side
   face (the step d dir) at a time, to its corner c_2 at the other end; c_3 and c_4 are c_1 and c_2
   moved by h in the direction out, away from the base *)
band[c1_, dir_, d_, l_, out_] := With[{c2 = c1 + Sum[d dir, {k, 1, l}]}, {c1, c2, c1 + h out, c2 + h out}];

(* S2 lies along the edge t_{p2} t_{p2+1}, outside B2: B2 is on the right of the edge, as it is walked
   clockwise, so the outward normal is the edge turned by +90 degrees *)
out2 = {-dir2[p2][[2]], dir2[p2][[1]]};
s2 = band[If[d2 == 1, t[p2], t[p2 + 1]], dir2[p2], d2, l2, out2];
p = s2;                                   (* the corners p_1, ..., p_4 of S2 *)

(* the signed distance from the line through the end p_2 p_4 of S2, positive away from S2 *)
normal = d2 dir2[p2];
fb[j_] := Expand[(b[j] - p[[2]]) . normal];
f = fb /@ shown;

(* ------------------------------------------------------------ the formulas on the page *)

page = {
  h Sin[4 a] + Cos[a] + Cos[2 a] + Cos[3 a] - Cos[4 a] - Cos[5 a] - Cos[6 a] - Cos[7 a] - 2,
  h Sin[4 a] + Cos[a] + Cos[2 a] + Cos[3 a] - Cos[4 a] - Cos[5 a] - Cos[6 a] - 2,
  h Sin[4 a] + Cos[a] + Cos[2 a] + Cos[3 a] - Cos[4 a] - Cos[5 a] - 2,
  h Sin[4 a] + Cos[a] + Cos[2 a] + Cos[3 a] - Cos[4 a] - 2};
Do[check["f(" <> names[[k]] <> ")", f[[k]] - page[[k]]], {k, 4}];
check["S2 lies in f <= 0: f(p_1) = -3", (p[[1]] - p[[2]]) . normal - (-3)];

(* ------------------------------------------------------------ the two ends of the interval *)

(* h_1(n) and h_2(n) (Section 2 of the home page), in a *)
h1[n_] := Which[
  n <= 12, (Sin[3 a] - Sin[2 a])/Cos[a],
  n <= 16, (Sin[3 a] - Sin[2 a])/(Cos[a] - Cos[3 a]),
  n <= 19, (Cos[4 a] + 2 - Cos[a] - Cos[2 a])/Sin[3 a],
  True, (2 Sin[5 a] - Sin[4 a] - Sin[3 a] + Sin[a])/(Cos[2 a] - Cos[5 a])];
h2[n_] := If[n == 11, Cos[a]/(Sin[3 a] - Sin[2 a]), (Cos[a] - Cos[3 a])/(Sin[3 a] - Sin[2 a])];

(* f(b_j)(h_side(n)) for the vertices in the tables, in a *)
value[k_, side_, n_] := page[[k]] /. h -> If[side == 1, h1[n], h2[n]];
Do[checkTrue["f(" <> names[[k]] <> ")(h_" <> ToString[side] <> "(n)) > 0 for 21 <= n <= 25",
    AllTrue[ns, positiveQ[value[k, side, #], #] &]],
  {side, 2}, {k, 4}];

(* every vertex b_j of B1, j = 0, ..., n - 1, is outside at both ends, and the smallest f(b_j) is at a
   vertex in the tables: every other f(b_j) is larger than one of those (f(b_j) - f(b_k) does not
   depend on h) *)
checkTrue["f(b_j)(h_1(n)) > 0 and f(b_j)(h_2(n)) > 0 for j = 0, ..., n - 1 and 21 <= n <= 25",
  AllTrue[ns, Function[n, AllTrue[Range[0, n - 1], Function[j,
    positiveQ[fb[j] /. h -> h1[n], n] && positiveQ[fb[j] /. h -> h2[n], n]]]]]];
checkTrue["the smallest f(b_j) is at a vertex in the tables for 21 <= n <= 25",
  AllTrue[ns, Function[n, AllTrue[Complement[Range[0, n - 1], Mod[shown, n]], Function[j,
    AnyTrue[Mod[shown, n], positiveQ[Expand[(b[j] - b[#]) . normal], n] &]]]]]];

(* the table: f(b_j)(h_side(n)) for the vertices in the tables rounded to six decimals *)
Do[Print["n=", n, ", h=h_", side, "(n): ", StringRiffle[
    Table[ToString[NumberForm[N[value[k, side, n] /. a -> 2 Pi/n, 20], {12, 6}]], {k, 4}], "  "]],
  {side, 2}, {n, ns}];

Print["passed ", passed, ", failed ", failed, "; signs decided exactly (RootReduce): ", exact];
Exit[If[failed == 0, 0, 1]];
